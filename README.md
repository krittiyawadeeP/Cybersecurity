#Cryptography Basics


A collection of classic cryptography algorithms implemented from scratch in C. This repository is created for learning the fundamental concepts of encryption and decryption through hands-on programmin

Key Features
- Shift Cipher
- Vigenère Cipher 
- Permutation Cipher
- One-Time Pad (OTP)
- ElGamal Cryptosystem 
- RSA Algorithm 
- Secret Sharing
